## Laboratórios executáveis

O repositório [SQL da Semana — laboratórios PostgreSQL](https://github.com/dirleiflsilva/sql-da-semana-postgresql) reúne tabelas, dados e consultas para acompanhar os artigos na prática.

O Docker Compose cria somente o PostgreSQL. Nenhum exemplo é executado automaticamente: o leitor entra no banco e executa manualmente os arquivos de cada episódio, seguindo a ordem indicada.

[Acesse os laboratórios no GitHub](https://github.com/dirleiflsilva/sql-da-semana-postgresql)
